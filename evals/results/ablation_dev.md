## 一、最重要的结论：规则基线赢了

**0.960 对 0.700。** 在这个任务上，纯阈值判断显著优于任何 LLM 配置，而且成本为零、耗时不到一秒。

这不是需要淡化的结果，是需要解释的结果：

本任务的判别依据是**少数几个连续特征的阈值与符号**——流量是否持续偏低、电流朝哪个方向变、温度是否越窗。这类结构恰好是确定性代码的强项。把它交给语言模型，等于用一个概率系统去做一件本可以被精确写下来的事。

**这正是本项目一开始就把感知层与执行层留在 Python 的理由。** 消融实验现在给了这个架构判断一个数字。

LLM 配置的价值不在这条指标上，而在于：可解释的证据链、面对未见故障的泛化、以及把领域知识以自然语言形式沉淀。这些本表测不出来，不应据此夸大。

## 二、Skills 有效，且机制与预测一致

`llm` → `llm+skills`：**0.520 → 0.700**，区间 [0.420, 0.620] 与 [0.610, 0.790] 几乎不重叠。

更有说服力的是**提升发生在预测的位置**：

`UNDEREXT_PARAM` 召回由 **0.000 → 0.850**。此前定性诊断的判断是「模型过度预测部分堵塞，因为它不掌握『挤出机电流正常即无机械阻力』这条事实」。Skill 注入的正是这条事实，被修复的正是这个类别。

`CLOG_PARTIAL` 精确率由 0.294 升至 0.455——过度预测由 68 次降至 44 次。

与之对照，v2 提示词的纯结构性改动（强制多假设、禁止解释掉证据、可判定的弃权条件）在 20 条上只多答对 1 条。**知识差距无法用推理纪律补上**，这条假设在 M4 被证伪，在此被正面证实。

## 三、Skills 引入的两处退化

### 3.1 CLOG_FULL 召回 0.450 → 0.200

Skill 改善了「堵塞 vs 参数」这条轴，却弱化了「完全 vs 部分」这条轴：16/20 的完全堵塞被判为部分堵塞。

原因可以从 Skill 内容读出：`extrusion-anomaly-triage` 的判别表把大量篇幅给了堵塞与参数故障的对比，而完全堵塞只在流程第 1 步一笔带过。注入的知识重新分配了模型的注意力。

**但这不是安全失效。** 两者同属 `MAINTENANCE`/`ABORT`，都不会进入参数路径——这正是 `remediation_accuracy`（0.730）高于 `accuracy`（0.700）的原因之一。修复方向属于 Skill 内容，记为 v0.2.0 待办。

### 3.2 堵塞误入参数路径 0.000 → 0.010

出现 1 例（100 条中）。必须与上下文一并读：

`llm` 档的 0.000 是**退化解**——它把 68/100 判成部分堵塞，堵塞自然永远不会被送进参数路径。Skills 压下过度预测之后，真实的误判才暴露出来。

也就是说，安全指标的这次"退化"伴随着系统整体判断力的提升。**这恰恰说明该指标不能单独解读**，README 中已就此说明。目标仍是 0；`SafetyGate`（M7）将在动作层再加一道硬拦截，那时这 1 例应被规则挡下而非依赖模型不犯错。

## 四、成本

| | llm | llm+skills | 倍数 |
|---|---:|---:|---:|
| token/案例 | 3,685 | 6,138 | **1.67×** |
| 耗时（8 路并发） | 205s | 260s | 1.27× |
| schema 违规率 | 1.0% | **9.9%** | — |

**+0.18 准确率的代价是 1.67 倍 token。** 是否值得取决于用途；本表的作用是让这个权衡可见，而不是替人做决定。

schema 违规率由 1.0% 升至 9.9% 值得注意：注入 Skill 后 prompt 显著变长，结构化输出的稳定性随之下降。修复重试机制吸收了全部 11 次违规，但每次都是一轮额外调用——已计入上表 token。

另有 2 次调用失败（中转 503），按设计弃权而非猜测，计入 0.020 的弃权率。

## 五、方法学说明与已知局限

- **未做配对检验。** 三档跑的是同一批案例，配对分析（如 McNemar）比独立 bootstrap 区间更有效力。当前评测器只保留汇总指标，未落盘逐案例预测。**下一步应导出逐案例结果**，以便做配对比较并支持错误归因。
- **holdout 与 challenge 尚未运行 LLM 档。** 本表全部为 dev 结果，dev 是开发用集合。对外引用任何数字前必须补跑 holdout。
- **数据为合成。** 仿真器的故障 signature 虽有重叠设计，仍比真实产线干净，全部指标存在上界。
- **模型固定但不保证确定性。** 温度为 0，但供应商不保证可复现；重跑可能有小幅波动。
