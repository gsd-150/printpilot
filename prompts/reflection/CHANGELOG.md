# 复盘提示词变更记录

与 `prompts/diagnosis/CHANGELOG.md` 同规矩：每版记录改了什么 / 假设是什么 /
实测变化多少 / 保留还是回滚。

本文件目前没有跨版本对比可写——复盘卡片的质量没有自动指标，验收是离线单测
（结构可解析、只进隔离区、传输失败不产卡）加上人工审阅本身。

---

## v1_baseline

- **改动**：首版。全轮记录 + 六条规则（只陈述记录内事实、单一合成案例不得
  泛化、不得声称外部来源、中文卡片、固定小节结构、英文小写 tags）。
- **假设**：把"可核查"写成硬规则，人工审阅的拒卡率会低于放任自由发挥。
- **实测**（2026-07-30，`deepseek-v4-pro`，`uv run printpilot loop --reflect --seed demo`）：
  **5/5 轮产出可解析卡片**并落入隔离区，零传输失败。预审（非正式审批）：抽查卡片
  的数字均可对照轮记录复核，无泛化、无编造来源；曾疑似外渗的 "cold pull" 实为轮
  记录内规则 rationale 的转述（`domain/faults.py` 故障目录），不属违规。
  **人工审批结论仍为空**——拒卡率要等审阅者裁决，此栏不代填。
- **状态**：保留（唯一版本）。
